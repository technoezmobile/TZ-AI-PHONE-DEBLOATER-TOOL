Engineering Principles & Architecture

Most debloating utilities treat packages as flat lists and run destructive ADB commands without verifying target state, user profile boundaries, or ROM dependencies. TZ AI DEBLOATER TOOL is built on five core safety pillars:

1. Multi-User Profile Isolation

Android manages packages independently per user ID (Owner 0, Work Profile 10, Dual Apps 999). Every action specifies --user <id> and checks post-execution state against that exact profile.

2. Separated Classification Dimensions

Package type (System, UpdatedSystem, User), catalog recommendation, and removal eligibility are computed as independent attributes. A catalog recommendation never overrides hardware protection rules.

3. Critical Vendor & Hardware Safeguards

Essential MediaTek, Qualcomm, and Samsung telephony/modem components (e.g. com.mediatek.telephony, com.mediatek.ims) are locked as Protected. Built-in ROM utilities are marked Review-Only.

4. Immutable Journal & Instant Recovery

Every executed modification is recorded in a local SQLite journal with original package state, command line, user profile, and timestamp. Restore uninstalled packages with one click via cmd package install-existing.

Console Capabilities

Package Explorer

Debounced search, categorized views (Debloat candidates, All packages, System & vendor, Removed for user), bulk preflight validation, and detailed package manifest inspection.

Optional AI Assistant

Propose tailored debloating plans using Gemini Direct (gemini-2.5-flash) or the TZ AI Gateway. Strict opt-in consent required; no telemetry sent without authorization.

Offline Verification

Every action executes ADB directly on your local system. No account creation, no cloud sync, and credentials reside in the Windows Credential Manager DPAPI vault.

Verified Hardware Compatibility

Tested and verified across Xiaomi HyperOS / MIUI (POCO, Redmi, Xiaomi), Samsung One UI, Google Pixel (AOSP), OnePlus OxygenOS, and Motorola devices. Non-root debugging operates safely within official Android permissions.
