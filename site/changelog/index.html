Changelog & Release Notes

Continuous refinement, verified hardware testing, and precision engineering updates.

Version 1.1.0 Latest Stable
November 10, 2026

1. Standalone Terminal Application (`tz-debloater`)

  • Headless Terminal Architecture: Complete terminal client running with 0 webview dependencies. Supports 11 subcommands: doctor, devices, users, scan, candidates, plan, apply, history, restore, config, and models.
  • Documented POSIX Exit Codes: Strict exit code contracts for CI/CD scripting: 0 (Success), 1 (Runtime error), 2 (Usage error), 3 (Confirmation declined), 4 (Policy violation), 5 (Device offline).
  • Machine-Readable JSON: Full --json support across all subcommands for headless pipelines and automation.

2. Cross-Platform OS Vaults & Advisory Locks

  • Cross-Platform Credential Vaults: Native credential encryption via Windows DPAPI, Apple Keychain Services, and FreeDesktop Secret Service with 0600 file fallback.
  • Cross-Process Advisory Locking: Atomic .lock files coordinate concurrent access between GUI and CLI instances with automated stale lock detection.
  • Universal ADB Locator: Automated discovery for macOS Homebrew/MacPorts and Linux system binaries.

3. Multi-Platform CI/CD & Public Documentation

  • Automated Workflows: Multi-platform matrix CI running on Windows, macOS, and Linux runners.
  • Authoritative Documentation: Comprehensive technical guides covering User Guide, CLI Reference, Installation, Troubleshooting, and Maintainer workflows.
Version 1.0.1 Initial Release Candidate
November 10, 2026

1. Package Classification & Selection Architecture

  • Three Separated Dimensions: Android package type (System, UpdatedSystem, User), catalog recommendation, and removal eligibility are decoupled. A catalog "Recommended" rating never overrides hardware protection rules.
  • Debloat Candidates as Default View: Package Explorer defaults to eligible debloat candidates, with dedicated views for All packages, System & vendor, and Removed for this user.
  • MediaTek & Modem Safeguards: Essential MediaTek vendor packages (com.mediatek.telephony, com.mediatek.ims, com.mediatek.wfo.impl) are locked as Protected. Uncertain vendor packages are marked Review-Only.
  • Built-in ROM Utilities Protection: MIUI Compass, Notes, Weather, Calculator, and Screen Recorder are kept out of automated debloating plans and marked Review-Only.

2. UX & Interaction Patterns (All 20 Patterns Implemented)

  • Command Palette (Ctrl+K): Instant keyboard navigation, package search, and system actions.
  • Persistent Sidebar: Remembers compact rail or full navigation preference across app restarts in localStorage.
  • Advanced Filtering: Active filter chips bar with individual removals and an instant "Reset all filters" button.
  • Debounced Search: 150ms debounce on Package Explorer search input eliminates UI frame drops on large inventories.
  • Animated Skeleton Loaders: Multi-row skeleton placeholders render while package inventories and device states refresh.
  • Preflight Batch Revalidation: Batch actions run validate_batch_selection, displaying an exact summary of targets and excluded protected items before execution.
  • Hidden Selections Counter: Displays explicit warnings when filtered views conceal selected packages.
  • Keyboard Navigation: Added Ctrl+1 through Ctrl+7 hotkeys, Ctrl+R rescan, and Ctrl+/ shortcuts reference modal.

3. Display Scaling & Layout Fluidity

  • Windows High-DPI Scaling: Eliminated the half-screen bug on 125% and 150% Windows display scaling by enforcing responsive flex containers in logical CSS pixels.
  • Narrow Window Grace: Two-column layouts in Settings and AI Assistant stack gracefully when the window width is reduced.
  • Chat Table Rendering: Render Markdown execution tables and logs as responsive structured tables rather than raw pipe delimiters.

4. AI Assistant & Model Protocols

  • Gemini Direct: Added direct Google Gemini API integration with support for gemini-2.5-flash.
  • Protocol Response Verification: Added strict response shape and generation validation across Chat Completions, Responses, and Anthropic APIs.
  • FreeLLMAPI Branding Removal: Neutralized third-party provider branding in favor of clean TZ AI Gateway configuration.
  • Explicit Shortcut Scopes: Distinct backend scopes for ReviewBloatware, ReviewTrackers, UninstallPromos, and ListCandidates.

5. Security & Vault Isolation

  • Production Vault Isolation: Credential unit tests run in an isolated in-memory test store and cannot overwrite user credentials in the Windows DPAPI vault.
  • Eliminated Runtime Fallback Override: Removed TZ_DEBLOATER_USE_FALLBACK_STORE from production release builds. Failed credential saves report honest errors rather than claiming persistence.
