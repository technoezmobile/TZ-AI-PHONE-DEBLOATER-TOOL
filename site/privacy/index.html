Security & Privacy First

Privacy Policy & AI Data Handling

Effective Date: November 10, 2026 · Product: TZ AI DEBLOATER TOOL v1.1.0

Core Guarantee: Zero Telemetry

TZ AI DEBLOATER TOOL does not include analytics, tracking beacons, error tracking daemons, or telemetry libraries. It does not contact any TZ Labs server during regular operation.

1. Local Device Execution & ADB Privacy

All package queries and ADB commands execute strictly between your Windows workstation and the connected Android phone via local USB cable or local Wi-Fi. No package inventories, installed application lists, or user profile configurations are transmitted to the internet.

2. Windows Credential Manager DPAPI Vault

AI provider API keys (such as Google Gemini, OpenAI, or Anthropic keys) are never stored in plain-text JSON or configuration files. They are encrypted using the Windows Data Protection API (DPAPI) and stored securely in the native Windows Credential Manager under the tz_debloater_vault namespace.

  • Keys are never logged in debug outputs or included in execution reports.
  • Deleting a connection profile immediately and permanently purges the secret from the Windows Credential Manager.

3. AI Assistant Data Boundaries & Explicit Consent

The AI Assistant feature is completely optional. By default, AI capabilities are gated behind an explicit AI Consent toggle.

Data Type Transmitted? Details
Personal Data (Contacts, SMS, Photos) Never The tool never reads or requests personal user data.
Device Identifiers (IMEI, MAC, Serial) Never Hardware serials and MAC addresses are stripped before formulating prompts.
Installed Package Identifiers Only with Consent Only public package IDs (e.g. com.facebook.katana) relevant to the debloating query are sent to the user's chosen AI provider.
Direct API Keys Client-Direct When using Gemini Direct, your request communicates directly from your machine to Google's API endpoints without passing through any intermediary.

4. Local Recovery Journal

Historical debloating actions are recorded in an encrypted SQLite database stored locally at: 

%APPDATA%\com.tzlabs.debloater\journal.db

This journal remains entirely on your machine. You can view, search, or clear this journal at any time from the Journal & Recovery tab.

5. Open Source Verification

TZ AI DEBLOATER TOOL is released under the GNU General Public License v3.0 (GPL-3.0). The complete source code is public and inspectable, allowing users and security researchers to verify network calls and data handling directly.
